# Proiect POO

## Descriere
Acest proiect este un exemplu de aplicație Java orientată pe obiecte (POO).
Include mai multe clase în folderul `Models` și un fișier principal `Main.java`.

## Structura proiectului
- `src/` - codul sursă
- `test/` - teste unitare
- `docs/` - documentație suplimentară
- `resources/` - fișiere auxiliare (configurări, imagini etc.)

## Tehnologii folosite
- Java 17
- IntelliJ IDEA
- Git & GitHub
